### clickup_get_workspace_tree

**Title**: Get ClickUp Workspace Tree

**Mode**: read (R)

**Annotations**: readOnlyHint=true, destructiveHint=false, idempotentHint=true, openWorldHint=true

List every space, folder and list in the ClickUp workspace as one tree, so you know what ids exist before calling a tool that needs one. The result is cached: call it once per session rather than before every lookup. Use clickup_get_list for the statuses and custom field definitions of one specific list once you have its id, and clickup_search_tasks to find a task by what it is about rather than by browsing where it might live. Examples: "what lists exist in this workspace", "where should I file a new task about the onboarding flow".

**Input parameters**

No input parameters.

**Output fields**

- `team_id`: string
- `spaces`: array of object {id, name, folders, lists}

**Mode**: read (R)

**Annotations**: readOnlyHint=true, destructiveHint=false, idempotentHint=true, openWorldHint=true

Resolve a name, username fragment or email fragment to the ClickUp workspace member(s) it matches, or resolve "me" to the authenticated user.
